Connect Google Sheets

The project is prepared for your Club_Registrations spreadsheet.

  1. Open your Google Sheet with its owner account and choose Extensions → Apps Script.
  2. Replace Code.gs with the contents of google-sheets/Code.gs in this project and save.
  3. Choose Deploy → New deployment → Web app. Execute as Me, access Anyone. The connection uses a secret key stored only on the server. Authorize the script when Google asks.
  4. Copy the Web app URL ending in /exec and paste it below.
